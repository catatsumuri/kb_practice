# パターン {#patterns}

> TypeSafeを使ったシステム構築のためのアーキテクチャパターン。

TypeSafeは、AIによる意思決定を担うより大きなシステムの中に組み込まれるよう設計されています。複雑なシステムの振る舞いへと組み合わさる、個別かつアトミックな意思決定という観点で考えることは、TypeSafeを最大限に活用するための重要なスキルです。

このセクションは、[TypeSafeのプリミティブ](/primitives)を理解し、[確信度の仕組み](/confidence)を把握していることを前提としています。まだの場合は、先にそちらをお読みください。

## パターン一覧 {#the-patterns}

| パターン | 概要 | メリット |
| - | - | - |
| [投機的ファンアウト](/patterns/fan-out) | 投機的なものを含む多くの質問を1回の呼び出しで送信し、関連するものをコードで判断する | コスト、速度 |
| [確信度ゲートルーティング](/patterns/confidence-routing) | 確信度を第2の意思決定軸として活用し、より安全なシステムを構築する | 信頼性、安全性 |
| [複合スコアリング](/patterns/composite-scoring) | 複数の分析軸を単一のスコアに統合する | コスト、信頼性、速度 |
| [インテントルーティング](/patterns/intent-routing) | ユーザーの意図を分類し、適切なハンドラーにルーティングする | コスト、速度 |
