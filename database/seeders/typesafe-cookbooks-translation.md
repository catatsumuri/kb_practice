# クックブック {#cookbooks}

> TypeSafeを実際の問題に適用したエンドツーエンドのレシピです。いくつかの質問から完全なパイプラインまでを網羅しています。

各クックブックは実践的な例です。実際のデータセット、それについて何かを判断するTypeSafeの質問、そしてそれらの判断を動作するシステムに変えるコードで構成されています。[プリミティブ](/primitives)と[パターン](/patterns)が具体的な問題においてどのように組み合わさるかを確認したいとき、または自分のプロジェクトの出発点としてコピーしたいときにご活用ください。

このセクションでは、[TypeSafeのプリミティブ](/primitives)を理解し、[確信度の仕組み](/confidence)を把握していることを前提としています。まだの場合は、先にそちらをお読みください。
