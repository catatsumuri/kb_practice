# ユースケース例 {#example-use-cases}

> TypeSafeのユースケースを業界別に探り、有望なアイデアをソフトウェアワークフローに変えましょう。

このマップを使って、あなたの業界でTypeSafeがどこに活用できるかブレインストーミングしてください。最も近い業界を開き、決定の例をスキャンして、自分のワークフロー内のドキュメントやアクションに適応させてください。

## ユースケース例のカテゴリ {#example-use-case-categories}

<Columns cols={2}>
  <Card title="AI自動化ソフトウェア" icon="blocks">
    AIと信頼性の高いソフトウェアを組み合わせて、人間のコパイロットなしにバックグラウンドで100万回実行できるようにします。コードがコントロールフローを担い（マークダウンファイルではなく）、TypeSafeがセマンティックな意思決定と言語理解を処理します。
  </Card>

  <Card title="リアルタイムアプリケーション" icon="zap">
    リアルタイムスピード（150ms）でのフロンティアインテリジェンスにより、AIは人間の知覚よりも速く意思決定できます。ゲームをプレイするようにプログラムしたり、UIに組み込んだりできるほど、速くかつスマートです。
  </Card>

  <Card title="ビッグデータ上のAI Map Reduce" icon="database-zap">
    100倍安価になることで、巨大なデータセットを処理できます。巨大なコーパスから関連情報を検索し、巨大なエージェントトレースを分類し、予測のための特徴を抽出します。
  </Card>

  <Card title="ユニバーサル検証" icon="badge-check">

  </Card>

  <Card title="ハーネスエンジニアリング" icon="wrench">
    Jevクエリを使ってハーネスをよりスマートにしましょう。モデルルーティング、セマンティックコンテキスト取得、LLMエラー検出とガードレール、光速かつわずかなコストでの推論トレース分類が可能です。
  </Card>
</Columns>

## 自動化ユースケース例 {#example-automation-use-cases}

<AccordionGroup>
  <Accordion title="検索と取得" icon="search">
    * セマンティック検索、スコアリング、ランキングでRAGパイプラインの埋め込みを置き換えるか補完します。
    * クエリと候補の関連性をスコアリングします。
    * ペアワイズ比較で結果を再ランク付けします。
    * より高い精度のためにクエリと候補をクロスエンコードします。
    * 下流のAIワークフロー向けに有用なコンテキストを選択します。
  </Accordion>

  <Accordion title="科学的発見" icon="flask-conical">
    * 系統的レビューのための包含・除外基準に対して論文をスクリーニングします。
    * 事前定義されたテーマやカテゴリを使って、インタビュートランスクリプト、自由回答式アンケート、フィールドノートのパッセージにラベルを付けます。
    * 引用されたパッセージが原稿や生成された要約の主張を支持しているか確認します。
    * コントロール、データセットの説明、実験設定など、欠落している方法論的詳細にフラグを立てます。
    * 論文をまたいでエンティティと関係を特定し、知見を支持するパッセージにリンクさせた研究知識グラフを構築します。
  </Accordion>

  <Accordion title="モデルルーティング" icon="route">
    * Jevを使って、各プロンプトを受け取るLLMを選択するカスタムルーターを構築します。
    * 特定のワークフローに合わせたルーティングルールとしきい値を設定します。
    * インテントとドメインを分類します。
    * 難易度とリスクを推定します。
    * より高コストなモデルが必要なリクエストをエスカレーションします。
  </Accordion>

  <Accordion title="LLMガードレール" icon="shield">
    * LLM呼び出しのわずかなコストで、すべてのLLM入力、出力、ツール呼び出しにセマンティックチェックを配置します。
    * ジェイルブレイクとプロンプトインジェクションを検出します。
    * ポリシー違反と機密データの露出を特定します。
    * ツール呼び出しエラーとレスポンス品質の失敗をリアルタイムで検出します。
    * 構造化されたチェック結果と確率をログに記録し、AIシステムとハーネスの障害をトレースしやすくします。
  </Accordion>

  <Accordion title="セマンティックコードリンティング" icon="code">
    * Jevクエリを使って、コードや文章に自動化されたセマンティックリントを追加します。
    * チームのコーディング規約やライティングガイドラインのためのチェックを定義します。
    * CIでこれらのチェックを実行し、レビューのために違反にフラグを立てます。
  </Accordion>

  <Accordion title="予測モデリングのための特徴抽出" icon="chart-spline">
    * Jevを使って、自然言語データから確率的特徴を抽出します。
    * これらの特徴を構造化データと組み合わせて、グランドトゥルースの結果があるタスクのモデルをトレーニングします。
    * オートリサーチワークフローを使って特徴定義を提案し、ホールドアウトされたグランドトゥルースに対してその予測価値を評価します。
  </Accordion>

  <Accordion title="採用" icon="users">
    * 明示的な職務関連の基準に対して、履歴書、応募書類、面接フィードバックを評価します。
    * 関連する経験を特定します。
    * 必要なコンピテンシーの証拠をスコアリングします。
    * 候補者を役割にマッチングします。
    * 候補者を採用マネージャーまたはリクルーターにルーティングします。
    * 不確かなケースを人間によるレビューにエスカレーションします。
  </Accordion>

  <Accordion title="リード生成" icon="user-round-search">
    * 会社プロファイル、役員の略歴、インバウンドメッセージを理想的な顧客プロファイルにマッチングします。
    * 業界適合性と企業の成熟度をスコアリングします。
    * 購買担当者の関連性、ペインポイント、購買意向を検出します。
    * リードを優先順位付けしてルーティングします。
  </Accordion>

  <Accordion title="カスタマーサポート" icon="headset">
    * 課題、製品領域、顧客インテントごとに受信チケットを分類します。
    * 通話トランスクリプトを処理して、顧客の問題、コミットメント、フォローアップアクションを抽出します。
    * 緊急度、不満、解約リスク、返金リクエストを検出します。
    * ケースを適切なチーム、キュー、または自動化ワークフローにルーティングします。
    * ポリシーと顧客のリクエストに対してサポートレスポンスを検証します。
  </Accordion>

  <Accordion title="保険請求" icon="clipboard-check">
    * 初回損失通知レポート、アジャスターノート、裏付け書類を分類します。
    * 請求の複雑さ、欠落情報、潜在的な不正の兆候を検出します。
    * ストレートスルー処理またはスペシャリストレビューのために請求を優先順位付けします。
    * 不確かなケースやリスクの高いケースを人間のアジャスターにエスカレーションします。
  </Accordion>

  <Accordion title="金融犯罪" icon="landmark">
    * 疑わしい特性について、トランザクションの説明、KYC書類、アラート履歴を評価します。
    * 不一致な名前、プロファイル、レコードをまたいでエンティティをマッチングします。
    * リスク、関連性、証拠の質でアラートを優先順位付けします。
    * 曖昧なケースをレビューのために調査担当者にルーティングします。
  </Accordion>

  <Accordion title="法務とコンプライアンス" icon="scale">
    * 契約書、ポリシー、規制上の申告、マーケティングの主張を分類します。
    * 欠落した条項、禁止された主張、ポリシー違反を検出します。
    * 明示的な法的またはコンプライアンス要件に対して書類を検証します。
    * リスクの高いケースや不確かな発見を法務またはコンプライアンスチームにエスカレーションします。
  </Accordion>

  <Accordion title="Eコマースマーケットプレイス" icon="store">

    * 商品をランク付けし、不確かなリストを人間によるレビューにルーティングします。
  </Accordion>

  <Accordion title="モデレーションとトラスト＆セーフティ" icon="shield-check">

    * コミュニティ、カスタマーサポート、SDRワークフロー全体でユーザーコンテンツと自動化された会話をモデレートします。

    * 規制コンプライアンスと禁止された主張を確認します。
    * クリエイティブ品質と広告とランディングページの整合性を評価します。
  </Accordion>

  <Accordion title="ゲーミング" icon="gamepad-2">

    * これらの指標を保険および引受ワークフローで使用します。
    * リスクタイプを分類し、疑わしい特性を検出します。
    * 深刻度をスコアリングし、レビューを優先順位付けします。
    * より広範なリスクモデルのための特徴を抽出します。
  </Accordion>

  <Accordion title="需要予測" icon="chart-spline">

  </Accordion>

## タスクカテゴリ例 {#example-task-categories}

| 決定の形状 | 使うべき場面 | 例 |
| - | - | - |
| **分類** | 1つの既知カテゴリが勝つべき場合 | インテント、トピック、部門、リスクタイプ、エンティティタイプ |
| **検出** | あるプロパティが存在する確率が必要な場合 | スパム、詐欺、緊急度、ジェイルブレイク、機密データ |
| **スコアリング** | 回答が順序付きルーブリック上にある場合 | 深刻度、関連性、品質、フラストレーション、適合性 |
| **ルーティング** | カテゴリが次のコードパスを選択する場合 | ツール使用、エスカレーション、モデルルーティング、サポートキュー |
| **検索** | 自然言語クエリにマッチするアイテムを見つける必要がある場合 | セマンティック検索、ドキュメント検索、候補生成 |
| **取得** | ワークフローが最も関連性の高いコンテキストやレコードを必要とする場合 | RAGコンテキスト、証拠取得、知識ルックアップ |
| **ランキング** | アイテムをセマンティックな関連性や品質で並べる必要がある場合 | 検索結果、レコメンデーション、候補の優先順位付け |
| **検証** | アーティファクトを特定の障害モードについて確認する必要がある場合 | 引用サポート、ポリシー違反、ツール呼び出しエラー、レスポンス品質 |
| **ML特徴抽出** | 下流の古典的MLモデルがセマンティックシグナルを必要とする場合 | 購買意向、製品への関心、競合圧力、解約シグナル |
| **構造化データ抽出** | 非構造化入力から既知のフィールドを回収する必要がある場合 | 候補者属性、注文フィールド、ドキュメントラベル |
